Bulk upload

Create or update many tickets from an Excel or CSV file. You review every row before anything is sent.

One row per ticket; only Title is required. A row with a Jira key, or a Task ID sent before, updates that ticket. Rows without a Task ID are matched by title, so uploading the same file again updates instead of duplicating. Assignee can be an email or the person's name in Jira; labels are added to a ticket's existing labels. Download the template to see all the columns.
