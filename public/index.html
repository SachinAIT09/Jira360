Post task to Jira

Create or update Jira tickets one at a time, or many at once from an Excel or CSV file. You see a preview before anything is sent.

Ticket details

Progress update (optional, for existing tickets)

One row per ticket. Only Title is required. A row with a Jira key, or a Task ID that was sent before, updates that ticket instead of creating a new one. Rows without a Task ID are matched by title, so uploading the same file again updates the tickets instead of duplicating them. Assignee can be an email or the person's name as shown in Jira. Labels in a file are added to a ticket's existing labels. Download the template to see all the columns.
