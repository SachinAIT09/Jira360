Google Sheet

Edits made in the sheet
Optional: exact "latest change wins" with an Edited at column

When the same cell changes in the sheet and in Jira between two syncs, the newer change is kept. Jira knows when its change was made; to give the sheet's edits an exact time too, add a column named Edited at (you can hide it), then in the sheet open Extensions → Apps Script, paste this and save:

function onEdit(e) {
  var sh = e.range.getSheet(), head = sh.getRange(1, 1, 1, sh.getLastColumn()).getValues()[0];
  var col = head.indexOf('Edited at') + 1;
  if (!col || e.range.getRow() === 1 || (e.range.getColumn() <= col && e.range.getLastColumn() >= col)) return;
  sh.getRange(e.range.getRow(), col, e.range.getNumRows(), 1).setValue(Date.now());
}

Without it, a sheet edit counts as made halfway between two syncs.

Make the sheet

With the service account key saved above, Jira360 can make a ready sheet: all the columns, dropdowns from Jira (status, priority, people, sprints), and your existing tickets filled in.

Or make it yourself (if creating isn't allowed for the service account)
  1. In Google Sheets, create a blank sheet (or File → Import the template).
  2. Share it with the service account as Editor.
  3. Paste its link in "Sheet address" above and Save settings.
  4. Click Set up the linked sheet: the columns and dropdowns are added, your own columns stay.
